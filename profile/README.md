<h1>DoKernel</h1>
<p>A foundation model for cause and effect in tables.</p>

[Website][website] · [Docs][docs] · [Quickstart][quickstart]

</div>

DoKernel reads a table of your data and answers two kinds of question about an outcome that you choose.

**What will a change do?**
"What happens to the breakdown rate if we change this setting?"
DoKernel predicts how the outcome moves when you push one column up or down.

**What caused a result?**
"What caused the 5% increase in breakdowns?" "Which gene knockout gives a better drug response?"
DoKernel shows how much each possible cause contributed to the outcome.
